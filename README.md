[**Carbon Window →**](https://github.com/abasukanga4/carbon-window)

## Healthcare: three different data problems

| Project | Question | Evidence to explore |
|---|---|---|
| [Hospital Performance Explorer](https://github.com/abasukanga4/nhs-ae-sql) | How does A&E performance vary over time and between providers? | 24 monthly NHS source files, 144 reconciliations, weighted SQL metrics, provider comparisons and an operational brief. |
| [Care Records Lab](https://github.com/abasukanga4/healthcare-data-quality) · [Interactive report](https://abasukanga4.github.io/healthcare-data-quality/) | What happens when records arrive broken, duplicated or out of order? | Incremental loads, relational checks, quarantine, correction releases, lineage and rollback using 2,000 clearly synthetic records. |
| [Hospital Demand Lab](https://github.com/abasukanga4/hospital-demand-forecasting) · [Interactive report](https://abasukanga4.github.io/hospital-demand-forecasting/) | Can a model improve on a simple seasonal forecast? | 188 months of public attendance data, three models, separate selection/calibration/test periods and uncertainty-band evaluation. |

These are independent portfolio studies using public aggregates or synthetic data—not
patient records or claims of clinical employment. Each repository includes methods, runnable
code, tests and limitations. The reporting project also includes a packaged Tableau workbook
and a dated record of its native review checks.
